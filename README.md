📌 Descripción General

El Sistema de Mesa y Bar es una aplicación desarrollada como proyecto académico en el SENA, diseñada para optimizar la toma de pedidos, gestión de inventario y control de comandas dentro de un restaurante o bar.
Permite a los meseros registrar órdenes de clientes en tiempo real, visualizar el estado de las mesas y mantener actualizado el inventario de productos de forma automática.

🧠 Objetivo

Facilitar el flujo de trabajo del personal de atención y cocina, reduciendo errores manuales y mejorando la eficiencia operativa del negocio gastronómico.

🛠️ Tecnologías Utilizadas

Lenguaje principal: JavaScript / PHP (según el caso real de tu proyecto)

Base de datos: MySQL

Frontend: HTML5, CSS3, Bootstrap

Control de versiones: Git & GitHub

Metodología: MVC (Modelo-Vista-Controlador)

⚙️ Funcionalidades principales

📋 Registro de pedidos por mesa o cliente.

🧾 Visualización del estado de cada mesa (disponible / en servicio / cuenta pendiente).

📦 Gestión de inventario automatizada según los pedidos.

👨‍🍳 Panel administrativo para el personal de cocina.

💵 Generación de facturas y control de ventas.
