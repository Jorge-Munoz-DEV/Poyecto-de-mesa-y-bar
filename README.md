<h1 align="center">🍽️ Sistema de Mesa y Bar</h1>
<p align="center">Aplicación web para la toma de comandas, gestión de pedidos e inventario | Proyecto académico desarrollado en el SENA</p>

---

## 📌 Descripción general

El **Sistema de Mesa y Bar** es una aplicación desarrollada como proyecto académico en el **SENA**, diseñada para optimizar la **toma de pedidos, gestión de inventario y control de comandas** dentro de un restaurante o bar.  
Permite a los meseros registrar órdenes de clientes en tiempo real, visualizar el estado de las mesas y mantener actualizado el inventario de productos de forma automática.

---

## 🎯 Objetivo

Facilitar el flujo de trabajo del personal de atención y cocina, reduciendo errores manuales y mejorando la eficiencia operativa del negocio gastronómico.

---

## 🧩 Tecnologías Utilizadas

- **Lenguajes principales:** JavaScript, PHP  
- **Base de datos:** MySQL  
- **Interfaz:** HTML5, CSS3, Bootstrap  
- **Control de versiones:** Git y GitHub  
- **Metodología:** MVC (Modelo - Vista - Controlador)

---

## ⚙️ Funcionalidades Principales

- 📋 **Registro de pedidos** por mesa o cliente.  
- 👀 **Visualización en tiempo real** del estado de cada mesa (disponible, en servicio o con cuenta pendiente).  
- 📦 **Gestión automatizada de inventario** según los pedidos realizados.  
- 🧑‍🍳 **Panel administrativo** para el personal de cocina.  
- 💵 **Generación de facturas y control de ventas.**

---

## 🧠 Metodología de Desarrollo

El sistema fue desarrollado siguiendo el **patrón de diseño MVC**, lo que permitió una clara separación entre la lógica de negocio, la interfaz y el acceso a datos.  
Además, se aplicaron **buenas prácticas de desarrollo y control de versiones** con Git, fomentando la mantenibilidad del código.
